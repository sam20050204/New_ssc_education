================================================================================
DATABASE QUERIES:
================================================================================

Current Implementation:
  1. Get all AdmittedStudents for selected year
  2. For each student:
     a. Get or create StudentFinanceDetail
     b. Retrieve FeePayment records: FeePayment.objects.filter(student=student)
     c. Extract payment information
  3. Pass complete data to template

Efficiency: O(n) where n = number of students (acceptable for small/medium apps)
